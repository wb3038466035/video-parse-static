# 影视播放 · 静态备用页

一个**不需要服务器**的视频播放页：粘贴腾讯/爱奇艺/优酷等视频页面链接，直接在浏览器里播放。

- 纯静态（HTML + CSS + JS 单文件），可直接托管在 GitHub Pages
- 不依赖任何后端、不含任何密钥：播放由第三方网页播放器在**你的浏览器**里完成
- 移动端 / 桌面端自适应，支持 `?url=视频链接` 直接打开

## 在线地址

https://wb3038466035.github.io/video-parse-static/

用法：打开上面的地址 → 粘贴视频页面链接 → 点「开始播放」→ 如未自动播放，点一下屏幕。

## 线路说明

页面内置两条备用线路（均为公开可用的第三方网页播放器）：

| 线路 | 说明 |
|---|---|
| 线路1 | 自动播放，无广告层 |
| 线路2 | 备用，如线路1不可用可切换 |

页面右上角「换线路」可循环切换，左上角可直接点选具体线路。

## 本地运行

下载 `index.html` 双击打开即可（或任意静态服务器）。以 `file://` 打开时剪贴板「粘贴」按钮可能受浏览器限制，建议用 Pages 地址访问。
